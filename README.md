# @taaltreelabs/on-device-llm

On-device LLMs for React Native and Expo, with automatic cloud fallback and context window management. Apple's on-device Foundation Model first, with an Android provider planned as a stretch goal.

**Not yet released, under construction.** This repository is currently a Phase 0 scaffold: the package layout, build tooling, and isolation checks described in [`docs/plan.md`](docs/plan.md) are in place, but the library itself (providers, context manager, router, hooks) has not been written yet. See [`docs/plan.md`](docs/plan.md) for the full plan and [`DECISIONS.md`](DECISIONS.md) for the architecture decisions made so far. Nothing here is published to npm; there is no installable version yet.
